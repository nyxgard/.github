## Nyxgard

**Check a file before you open it, and see why.**

Nyxgard is a malware scanner for Windows. It checks files on your PC before you open them and tells you what it found
and why it matters, in plain words. No unexplained red warnings, no blind trust.

We build Nyxgard in Yerevan, Armenia. We started it because the tools we used ourselves were either powerful but hard
to read, or simple but silent about their reasons.

### Where things are

- Website and download: [nyxgard.io](https://nyxgard.io)
- Support: [support@nyxgard.io](mailto:support@nyxgard.io)
- Found a security issue? Please read [nyxgard.io/security](https://nyxgard.io/security) and write to
  [security@nyxgard.io](mailto:security@nyxgard.io). Do not open a public issue for it.

### What's next

Nyxgard is in active development. Next on our roadmap: AI explanations of results in plain words, a deeper analysis
mode for suspicious files, and the source code of the Windows app here on GitHub, so anyone can check what it does.
